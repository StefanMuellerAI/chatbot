# Freebie

Passwortgeschützter Schulungs-Chatbot (Spielumgebung) mit Modellen von OpenAI und Anthropic (Claude):
Datei-Upload, Bildgenerierung, MP3-Transkription, Spracheingabe, Websuche, einstellbarer
Thinking-Effort, Artefakte (HTML, Diagramme, Charts) und ein Admin-Bereich zur Modellverwaltung.
Läuft auf Vercel. Prompt Caching und ein Antwort-Cache für identische Anfragen schonen die API-Budgets.

Der vollständige Umsetzungsplan steht in [PLAN.md](PLAN.md).
