# Freebie

Passwortgeschützter Schulungs-Chatbot mit Modellen von OpenAI und Anthropic (Claude): Datei-Upload,
Bildgenerierung, MP3-Transkription, Spracheingabe, Websuche, einstellbarer Thinking-Effort, Artefakte
(HTML, Diagramme, Charts) und ein Admin-Bereich zur Modellverwaltung. Konsequentes Prompt Caching
schont die API-Budgets.

Der vollständige Umsetzungsplan steht in [PLAN.md](PLAN.md).
